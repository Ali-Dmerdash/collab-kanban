# collab-kanban
A production-style fullstack monorepo for a collaborative Kanban board (Trello-like), built with Bun workspaces.   Backend: Node/Express/TypeScript, Prisma, PostgreSQL, Redis, JWT auth, Socket.IO real-time updates, Jest tests.   Frontend: Next.js App Router, ShadCN UI, TanStack Query, Tabler Icons, Dockerized infra.
